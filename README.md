# Interval Plain · Interval Timer

Native iPhone/iPad interval routine app, in development. Apple accepted the title on October 15, 2026. Shipping and production QA remain in progress.

Original linked-interval icon, restrained charcoal/tangerine/mint interface, deterministic continuous-clock timing, atomic local storage, native local speech and StoreKit 2 non-consumable library. One reusable routine free; no account, ads, developer data collection or product backend.

Engineering source is private. This public showcase contains only product/support/privacy material. Six real iPhone marketing frames are included after native Build3 capture and full-size/thumbnail visual QA. iPad artwork and App Store submission remain in progress. No App Store link exists yet.
